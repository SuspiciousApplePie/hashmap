# Hashmap

Hashmap exercise using JavaScript

## Tools:

- Jest
- Babel (For Jest compaitbility)
- Prettier (VSCode ext.)

## Methods:

- hash
- set
- get
- has
- remove
- clear
- keys
- values
- entries

## Things I learned

- Implementing my `hashmap` understanding.
- Utilizing `Linked List` for collision.

## Requirements

- NodeJS
- git

## How to use

1. Clone using this command: `git clone https://github.com/SuspiciousApplePie/hashmap.git`.
2. Install Jest: `npm install --save-dev jest`.
3. Install Babel: `npm install --save-dev @babel/preset-env`.
4. Done.
